# Hồ sơ bàn giao cho Claude

Thư mục này là nguồn ngữ cảnh tập trung để một trợ lý khác hiểu đúng bài tập
lớn Telco Customer Churn, không phải một tập yêu cầu mới.

| File | Mục đích |
|---|---|
| `PROJECT_CONTEXT.md` | Bối cảnh, phạm vi, dữ liệu, pipeline, kết quả đã chốt và các lưu ý học thuật. |
| `FILE_MAP.md` | Bản đồ thư mục, file đầu vào/đầu ra và lệnh tái tạo artifact. |
| `PROMPT_FOR_CLAUDE.md` | Prompt hoàn chỉnh có thể dán trực tiếp cho Claude. |

Đọc `PROJECT_CONTEXT.md` trước, sau đó dùng `FILE_MAP.md` khi cần xác minh
code hoặc artifact. Không coi các file trong `docs/archive/` là tài liệu vận hành.
